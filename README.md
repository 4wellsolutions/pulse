# PULSE

A 56-second wordless film, drawn entirely in code: no image model, no video model, no 3D.

A hospital monitor goes flat. The last blip does not disappear: it runs out of the window as one unbroken line of
light, draws every place it crosses, and collects a rhythm in each one (rain on tin roofs, a steam train, a dhol at a
street wedding, a skipping rope, the sea). It loses them all in a silent snow field, is called back by a child's laugh
from a lit window, races home and starts the heart again. The trace writes the title.

**Watch:** [`renders/pulse_9x16.mp4`](renders/pulse_9x16.mp4) (1080 x 1920) and
[`renders/pulse_1x1.mp4`](renders/pulse_1x1.mp4) (1080 x 1080). 24 fps, 12 shots, 1,344 frames each.

## Play it in the browser

Open `index.html` in Chrome and press Play or Space. The link beside the time switches between 9:16 and 1:1
(`index.html?ar=1x1`). The scrub bar jumps to any second; the picture is a pure function of film time.

## How it is made

- One `<canvas>`, drawn in 2D from film time alone (`window.renderAt(t)`), so any frame renders in any order.
- `src/core.js`: the timeline, the five rhythm patterns, and `ground(x, t)`, the path the line runs along
  (rooftops, rail, string of lights, skipping rope, waves).
- `src/places.js`: the line art of each place. Everything is stroked with one gradient that is bright where the
  line is, a blue trace behind it and only a hint ahead of it.
- `src/main.js`: the line itself and its five beads, the camera, the hospital room, the title, the impact frames.
- `tools/make-audio.py`: the soundtrack, written note by note (heartbeat, rain ticks, train clack and bass, dhol,
  claps and a small tune, chords), plus a few recorded sounds of each place from `assets/sfx`. The rhythm patterns
  in this file and in `src/core.js` are the same numbers, so every hit you hear is a hit you see.
- `tools/render.mjs`: captures frames with Playwright driving the installed Chrome, then ffmpeg joins them with
  the score.

## Run it

Needs Node 18+, ffmpeg on the PATH, and Chrome (or see `PULSE_BROWSER` in `tools/render.mjs`). The audio script
needs Python with numpy, scipy and soundfile. All paths are relative to this folder.

```bash
npm install                                  # Playwright
node tools/render.mjs stills 9x16 9 20 39    # preview/9x16/still-00.jpg ...
node tools/render.mjs film 9x16              # renders/pulse_9x16.mp4
node tools/render.mjs film 1x1               # renders/pulse_1x1.mp4
python tools/make-audio.py                   # rebuilds assets/audio/score.wav and score.mp3
```

The render uses the committed `assets/audio/score.mp3` unless you have rebuilt `score.wav`.

## Recorded sounds

The score is synthesized, with nine short recordings of the places mixed quietly under it. They are free Mixkit
sound effects, which may be used in a finished work but not passed on as files, so they are not in this
repository. The committed `score.mp3` already contains them. If you rebuild the audio without them, the script
says which are missing and leaves them out; the rhythm score is unchanged.

To include them, put any recordings with these names in `assets/sfx/` (mp3):

| File | What it is |
| --- | --- |
| `breeze_trees` | a light breeze in trees |
| `rain_storm` | steady rain (Mixkit "Rain and thunder storm") |
| `train_horn_distant` | a distant train horn (Mixkit "Distant train horn") |
| `steam_train_passing` | a steam train passing (Mixkit "Steam train passing") |
| `fair_crowd` | a happy outdoor crowd |
| `child_laugh` | a child laughing, about 1.5 s |
| `sea_waves_close` | waves close by (Mixkit "Close sea waves loop") |
| `wind_forest` | cold wind |
| `wind_swoosh` | one fast whoosh |

`SPEC.md` is the director's brief, `STORYLINES.md` has the ideas that were not built, and `REVIEW.md` says what was
checked and what was not.
